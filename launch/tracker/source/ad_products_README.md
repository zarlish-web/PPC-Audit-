# ad_products_2026-10-22.csv

Lists the colours that had ad activity (impressions or spend) in each ad group from 16 to 21 Oct, taken from Sellerboard.
It is **not** the list of ads set up in each ad group. Sellerboard and the command center only return products with activity.

On 22 Oct the Amazon Ads console showed all 5 Queen colours (White, Regal Purple, Navy Blue, Midnight Black, Cool Grey) enabled in SP-01, SP-24 and SP-06. Sellerboard had listed only Regal Purple and Midnight Black for SP-06.
A "no" in this file means the colour had no activity, not that it was left out.
For the full set of ads, use the Sponsored Products bulk file, rows where Entity = Product Ad.
