# PPC SOP digests

Working-reference digests of the 30 PPC SOP PDFs in the repository root. One file per SOP. Each one covers
scope and boundaries, triggers, procedures, every threshold and Criteria System v4.0 rule ID it cites, the
data inputs it reads, outputs, decision rights, facts about the current account, and open amendment items.

The digests are a reading aid. The PDFs remain the source of record. Every SOP defers its thresholds to the
*Master PPC Decision Criteria System v4.0*, which is not in this repository.
